# 求职 Tracker

一个用 Python3 + Flask + SQLite 写的求职进度记录工具，前后端不分离，只有一个页面加一个详情页。

## 功能

- **新增岗位**：填写「开始日期」「公司名称」「职位名称」「Job 状态」，点击「创建」即可。
  状态默认为 **打招呼**，可选值为：打招呼 / 发简历 / 电话沟通 / 一面 / 二面 / 三面 / Offer / 终止。
- **岗位列表**：默认每页 10 条，按开始日期倒序排列，带「上一页 / 下一页 / 页码」分页。
- **直接改状态**：列表里每行都有状态下拉框，选好后点「保存状态」即可修改，
  每次修改都会记录修改时间。
- **删除岗位**：列表里每行都有「删除」按钮，删除前会弹窗确认。
- **岗位详情**：点「详情」可以看到岗位的完整信息，以及**状态流转记录**（每次改状态的时间）。

界面按老年人的使用习惯设计：基础字号 20px、按钮最小高度 46～52px、高对比度配色。

## 环境要求

- WSL（或任意 Linux）环境
- Python 3.12.x
- 首次安装依赖需要联网

## 安装与启动
<!--我的运行环境是wsl,发布版为job-tracker-->
在项目根目录下执行：

```bash
bash start.sh
```

脚本会自动完成三件事：

1. 创建虚拟环境 `.venv`
2. 安装 `requirements.txt` 里的依赖（Flask）
3. 启动应用

启动成功后，用浏览器打开：

```
http://127.0.0.1:5000
```

停止服务按 `Ctrl+C`。

### 换端口启动

```bash
PORT=8080 bash start.sh
```

### 手动安装（不使用 start.sh 时）

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

## 数据库

- 使用 SQLite，数据库文件为 `job_tracker.db`，位于 `main.py` 所在目录。
- **首次启动时自动创建**，无需手工建库或初始化。
- 共两张表：
  - `jobs`：岗位信息（开始日期、公司名称、职位名称、当前状态、创建时间、最近修改时间）
  - `job_status_history`：状态流转记录（岗位 id、状态、修改时间）

想清空所有数据，直接删除 `job_tracker.db` 后重新启动即可。

## 验收步骤（照着做即可）

1. 进入项目目录，执行 `bash start.sh`，等待依赖安装完成、出现启动提示。
2. 浏览器打开 `http://127.0.0.1:5000`。
3. 在上方「新增岗位」里填开始日期、公司名称、职位名称，状态保持默认的「打招呼」，点「创建」。
   页面顶部会出现创建成功的绿色提示，下方列表出现这条记录。
4. 重复第 3 步多录入几条（超过 10 条可以看到分页效果）。
5. 在列表里把某条记录的状态改成「一面」，点「保存状态」，会看到状态已更新、
   「最近修改」时间变成当前时间。
6. 点这条记录的「详情」，可以看到基本信息以及状态流转记录（含每次修改的时间）。
7. 点列表里的「删除」，确认后该记录消失。

## 常见问题

- **端口被占用**：换一个端口启动，例如 `PORT=8080 bash start.sh`。
- **Windows 浏览器打不开 127.0.0.1:5000**：确认 WSL 里的服务已启动（终端没有报错），
  WSL2 默认会把 WSL 的 127.0.0.1 转发到 Windows。
- **重新开始**：删除 `job_tracker.db` 文件后重启即可。
